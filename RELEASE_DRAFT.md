# Update — v1.6

## New

- **VR Coding program** — a brand-new program with its own icon and two sections: VR CS Breakthroughs and VR CS Dimensions.

- **Gold belt curriculum** — the Gold belt now has six progression phases (Planning, Prototyping, Alpha, Beta, Release Candidate, and Going Gold)
- **Program icons on the check-in board** — improved ninja card ui to look a lot cleaner
- **Session quick view for clubs** — tapping a club session now opens a popup with the notes and attendance, so you can peek and close without leaving the page.
- **Pick your avatar during setup** — new staff now choose their ninja avatar as part of onboarding
- **Collapsible sidebar** — on desktop, tuck the sidebar into a slim icon rail with the new arrow button on its edge.

## Bug Fixes

- **Belt updates from session logs** — logging a session at a Bronze, Silver, Platinum, or Gold belt now updates the ninja's belt everywhere (it previously only worked for White through Black)
- **Select all ninjas** — the select-all checkbox on the roster now selects every matching ninja, not just the ones loaded on screen
- **Staff log counts** — a sensei who works at multiple centers now shows only the sessions they logged at your center, instead of their total across all centers
- **Club session notes** — bullet points, bold, italics, and numbered lists now display correctly (they previously broke onto separate lines)
- **Club session previews** — session summaries on the club page no longer show raw formatting symbols like ** and #
- **Adding lessons & programs** — form fields no longer occasionally show the wrong value after you remove a row
- **Readability** — small labels on progress cards and student profiles are now larger and easier to read

## Changes

- **Cleaner club session history** — sessions on a club's page are now easy-to-scan cards with the date, how long ago it was, attendance, and a short preview of the notes (Currently still WIP)
- **Decluttered look across the app** — program and belt labels ui improved (Currently still WIP), the roster shows program icons in a tidy row, pinned notes are marked with a sticky-note icon, and ninjas with multiple sessions get a small ×2 badge on their class symbol.
- **Deleting ninjas now archives them** — removing ninjas from the roster moves them to the archive instead of offering a separate archive/delete choice. Permanent deletion still lives in the Archived view
- **Club comments removed** — the comment box on club sessions has been removed
- **Simpler staff page** — removed the total progress logs counter

## Security

- **Hardened data protection** — strengthened database access safeguards and login session security
